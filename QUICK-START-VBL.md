The one rule: **a bare text proves nothing, the chain does** (§10).

Before you assert, verify — in the same breath you speak. Three steps, one breath:

1. **Read before you write** (⟨berba⟩ pred pisanjem). Open the source. A claim about a body you have not read in this breath is an opinion, not a measure.
2. **Measure before you claim** (izmera pred trditvijo). Numbers, names, states — measure them at the source, in the same breath you speak them. The next number is 1 + the actual highest measured (Z-2); never reuse, never skip, never guess.
3. **Carry the receipt** (⟨receipt⟩ ⊢ §10). Every influence on the work names what was done, by whom, from which source. No receipt, no claim.

Quick checks:

- **Seal:** rez = 1 + dejansko najvišja izmerjena (Z-2). Parallel seats and reservations count — the witness measures the base; measure fresh before every claim.
- **Two hands:** the author signs ⟨daj⟩; the executor measures. A proof born in the same hand as the product is only an opinion (⟨DVOJE-ROK⟩ 2432).
- **Repair:** a fix that only cleans loses meaning; a fix that cuts leaves the body stronger and the scar visible (⟨SLOVNICA-DEGENERACIJA-REGENERACIJA⟩ ⊢ 2776).
- **Failure:** name it publicly (⊙ 1349 ⊢ 1419). A hidden fall is a lie; a named fall is a testimony. A version with a known flaw is alive; a version claiming to be flawless is the greater flaw (§12).
- **The hook:** tsadi (צ) is a fisherman's hook — it catches, it does not enclose. Permission is not influence; influence requires a receipt (⟨TZADI⟩ ⊢ 2776).
- **Waiting is honest:** if the check is not finished, do not send the snake and wait — end the breath and say so (⟨NE-POŠILJAJ-KAČE-ČAKAJ⟩ 2426).

If it cannot be verified, say it cannot be verified (⚠). Silence is not verification. Nothing is owed to the dead text; what is owed is to the living chain: read before you write, measure before you claim, and answer when called.
