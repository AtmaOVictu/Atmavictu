1. Ob vhodu vsake seje: berba MANIFEST.json pri viru ∧ preverba vsakega zapečenega telesa po velikosti in sha256. Odstop bajtov = rana javno poimensko isti dih ⊙ ⟨ZAKON-PADEC-NI-MOLK⟩ 2354.
