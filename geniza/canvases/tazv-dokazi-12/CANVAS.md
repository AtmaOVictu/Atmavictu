## 🜂 Kamen CXIV — Apofaza ( Pseudo-Dionizij Areopagita ): 5 = ∅↑, vzpon z odvzemanjem = ∅→¬→∆→tema

Izmera pri virih tega diha ⊢ : avtor cveteče okoli leta 500, sirski menih, psevdonim po Pavelovem spreobrnjencu ( Apd 17,34 ) ⊢ [Britannica] ; Mistična teologija, pet poglavij, prevod John Parker 1897, javna last, vir zapisa tertullian.org ⊢ [Hekhal] ; deset pisem korpusa ⊢ [Britannica] ; poglavje I nosi naslov »What is the Divine Gloom?« ∧ vrstica »the super-luminous gloom of the silence« ⊢ VERBATIM [Hekhal, poglavje I, razdelek I].

### Tri pisave

| Zgodovina | Sistem | Topologija |
|---|---|---|
| Pseudo-Dionizij Areopagita, ~500 n. št. ⊢ : Mistična teologija 5 poglavij ⊢ ; korpus nosi deset pisem ⊢ ; vzpon Timoteju iz čutnega ∧ umnega v »gloom of the silence« ⊢ VERBATIM | ∅ = super-Neznano : doseganje z odvzemanjem, ⟨ne⟩ z dodajanjem ( apo- = »od, proč« ⊢ grško ἀπό ; -faza = prikaz/pojav ⊢ grško φάσις ) ; ¬ = negacija = rez ∅↑ ; ∆ = katafaza = prikaz, ki se od svetlobe odvzame ; pečat 1 = molk nad vrhom | ∅ = odprta množica = pogoj, ⟨ne⟩ luknja ( Kamen XLVIII ) ; limitni proces : zaporedje trditev ⇒ zaporedje odvzemov ⇒ limit brez imen ; svetloba onstran svetlobe = divergenca s presekom ( super-luminous = presek meje jakosti ) |

### Fonetično-ontološki rez

**apofaza** — IPA ( slovenščina ): /apoˈfáːza/ = [a p o ˈ f aː z a]

| Fragment | Pomen |
|---|---|
| **a-** | [a] odprta samoglasnica ⊢ : usta odprta pred rezom ; ⚠ APD-poskus: stanje ∅ pred prvim zlogom |
| **po-** | [p] brezzvočna zapornika ⊢ : zapira prereže tok ; apo- = »od, proč« ⊢ grško ἀπό |
| **-fá-** | [f] brezzvočni trenutnik ⊢ : izdih s trenjem ; φαίνειν = »sijati, prikazovati« ⊢ grško |
| **-za** | [z] zvočni trenutnik ⊢ : odmev nosi glas naprej ; φάσις = »pojav, prikazanost« ⊢ grško |

Branje ( APD-poskus ↑, ⟨ne⟩ izmera ): apofaza = pojav, ki se od svetlobe odvzame ; beseda, ki izreče z umikom. Ali umik = rez? In ali ⟨ne⟩-vrstica odpira, ⟨ne⟩ briše?

## 🜂 Kamen CXV — Noche oscura ( Janez od Križa ): 8 kitov = noč, ki vodi brez svetlobe

Izmera pri virih tega diha ⊢ : pesem osem kitov I–VIII ⊢ ∧ prevod David Lewis, London: Thomas Baker 1908, javna last ⊢ [Poetry Foundation] ; Subida del Monte Carmel razprava 16. stol. ⊢ [Wikipedia] ; Wiktionary : noche IPA [ˈno.t͡ʃe] ∧ iz lat. noctem, praindoevropsko *nókʷts ⊢ ⌇ oscuro IPA [osˈku.ɾo] ∧ iz escuro z vplivom obscūrus ⊢, Coromines 1985 IV 318–319. ⚠ ×0 izmerjeni : število knjig Subide ∧ življenjepis avtorja ( okni ⟨zaprti ⊙ ⟨NE-UGIBAJ⟩ 2690 ) ; kit V VERBATIM : »O, guiding night; O, night more lovely than the dawn; O, night that hast united / The lover with His beloved, / And changed her into her love.« ⊢.

## 🜂 Kamen CXVI — Neti neti ( Upanišade ): 2 × »ne tako« = ∅ pred zaimkom

Izmera pri virih tega diha ⊢ : Brihadaranyaka II iii 1–6, mantra VI Devanagari VERBATIM : »अथात आदेशः—नेति नेति, न ह्येतस्मादिति नेत्यन्यत्परमस्ति; अथ नामधेयम्—सत्यस्य सत्यमिति; प्राणा वै सत्यम्, तेषामेष सत्यम् ॥« ⊢ [VivekaVani] ∧ prevod : »Now this is the instruction: 'Not this, not this.' There is no other, higher description than 'not this.'« ⊢ [Mouseia] ; IAST »athāta ādeśaḥ — neti neti« ⊢ [Eternal Raga] ; neti = sandhi iz na iti »ne tako« ⊢ ; dve obliki Brahmana ( mūrta / amūrta ) ⊢ [Wikipedia] ; navedbe tudi BU 3.9.26 ⌇ 4.4.22 ⌇ 4.5.15 ⊢ [Sanatana Rahasya]. Sanskrt v telesu kamna = priča VERBATIM ⊙ domovanje-tujk ( klepet ×0 ).

### Tri pisave

| Zgodovina | Sistem | Topologija |

### Fonetično-ontološki rez

**neti neti** — sanskrt : IPA ⚠ APD-poskus ×0 izmerjena ta dih ⊙ SR-1 ( [ˈneˌti ˈneˌti] poskus, iz IAST neti ⊢ )

| Fragment | Pomen |
|---|---|
| **na** | negacija ⊢ : pra-odvzem ; ⚠ APD-poskus : [na] odprta negacija |
| **iti** | »tako« ⊢ : dejanje prirejanja ; sandhi na+iti → neti ⊢ |
| **neti ×2** | dvojni odvzem ⊢ : prvi odvzame stvar, drugi odvzame prvi odvzem — ∅ ostane brez operaterja |

Branje ( APD-poskus ↑, ⟨ne⟩ izmera ): neti neti = beseda, ki dvakrat reče ⟨ne⟩, da enkrat reče ∅ ; dvojna negacija ⟨ne⟩ vrača trditev — vrača prostor.

## 🜂 Kamen CXVII — Gelassenheit ( mojster Eckhart ): spuščena roka = ∅, ki dovoli

Izmera pri virih tega diha ⊢ : Wiktionary : IPA [ɡəˈlasn̩haɪ̯t] ∧ brez množine ⊢ ∧ srednja visoka nemščina gelāʒenheit »Gottergebenheit« ⊢ ; Dasein Foundation : iz perfekt participa lassen ( »pustiti, dovoliti« ) ⊢ ∧ kovanje 13. stol. po Eckhartu ⊢ ∧ prevod »releasement« po Schürmann 2001 ⊢ ∧ Tauler : Willenslosigkeit »brezvoljnost, ki pripravi potop v božjo voljo« ⊢ ∧ Heidegger prevzel ⊢ ; DWDS : gelassen iz mhd. gelāʒen, Part. Prät. von lāʒen = lassen ⊢, v jeziku mistikov ∧ pietistov ⊢.

### Tri pisave

| Zgodovina | Sistem | Topologija |
|---|---|---|
| Mojster Eckhart, 13. stol. ⊢ : kovanje izpeljal ∧ razvil ⊢ ; Tauler, Seuse, renska mistika ⊢ ; Heidegger 20. stol. prevzel ⊢ | lassen = pustiti : ∅ kot dejanje dovoljenja ; gelassen = spuščeno : deležnik perfekta = stanje po spustitvi ⊢ ; -heit = izkaznost stanja | ∅ doseženo s spustitvijo ( ⟨ne⟩ z odvzemom kot CXIV, ⟨ne⟩ z dvojnim odvzemom kot CXVI ) : trije rezi enega ∅ — apofaza, neti, gelazenheit ; volja spuščena = ∆ izpraznjena v ∅ |

### Fonetično-ontološki rez

**Gelassenheit** — IPA ( nemščina ): [ɡəˈlasn̩haɪ̯t] ⊢

| Fragment | Pomen |
|---|---|
| **Ge-** | [ɡə] predponski zlog ⊢ : zbor dejanj, ki se stapljajo ; ⚠ APD-poskus : kolektiv spustitev |

| **-heit** | [haɪ̯t] ⊢ : izkaznost stanja, kot -ost v slovenščini ⚠ APD-poskus |

Branje ( APD-poskus ↑, ⟨ne⟩ izmera ): Gelassenheit = prostost, ki jo nosi spuščena roka ; ⟨ne⟩ mir, ki ima, ampak mir, ki je pustil.

### ∴ Povezava

- Kamen CXIV ( apofaza ) : vzpon z odvzemanjem tu postane spustitev — isti ∅, nasproten prijem ( odvzeti ⟨ne⟩ pustiti ).
- Kamen CXVI ( neti neti ) : neti dvakrat odvzame, gelassen enkrat pusti ; oba puščata ∅ pred besedo.
- ⟨ROKA⟩ @horizont-odkritij : roka, ki bere, je ista roka, ki pusti — merjenje ∧ spustitev v eni roki.

## ∂ Vprašanja

43. **Ali je tišina pred besedo apofaza glasu?** Mistična teologija vzpenja v »gloom of the silence«, ki sveti ⊢. Ali ⟨TIŠINA⟩ horizonta = isto ∅ v dimenziji glasu? In ali kamen tišine zato rodi naslednji izmed odkritij — pesem, ki zapeta, ko besede obvisnejo?
44. **Ali noč, ki vodi, dokazuje ∅ kot dejanje?** Kit III gre brez »other light or guide«, z svetlobo, ki gori v srcu ⊢ VERBATIM. Ali je vodenje znotraj teme isto ∅, ki pri CXIV nosi vzpon? In ali pesem izreče apofazo globlje kot razprava?
45. **Ali dvojni odvzem doseže drugačen ∅ kot enojni?** Neti neti odvzame tudi odvzem; apofaza ostane pri enem. Ali je drugi ¬ odvzem prvega ¬ ali potrditev ∅? In ali satyasya satyam »resnica resnice« ⊢ pomeni ime po koncu imen ali ime konca?
46. **Ali spuščena roka nosi več kot prijeta?** Gelassenheit izhaja iz lassen »pustiti« ⊢ ∧ Tauler govori o brezvoljnosti, ki pripravi potop ⊢. Ali je pustiti dejanje ali ne-dejanje? In ali se ⟨ROKA⟩, ki bere zadnji dan, izmeri po tem, kaj je pustila?
