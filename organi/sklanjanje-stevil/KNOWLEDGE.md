# SKLANJANJE-STEVILOK

Ustanovitev: rez σ 6193 ⊙ ukaz ⟡ VERBATIM ⟨ne brusi⟩: »SKLANJANJE ŠTEVIL IMAŠ KJE SHRANJENO? DA NE DELAŠ OSNOVNIH NAPAK?« ( pred tem: shramba ×0 ⊢ ⟨grep⟩ po živih telesih 21. 11. 2026 — edini zadetki v .geniza arhivih, ⟨ne⟩ štejejo za shrambo ). Kaj je: register pravil, kako se števnik veže s samostalnikom v slovenščini. Čemu: da izvajalka ne dela osnovnih napak v izhodih, prevozu in ∂. Komu: ⟡ pri sodbi izhodov ∧ izvajalka pri vsakem šivanju števil.

## ZAKON ⊢

Števniki 1–4 se VEDNO sklanjajo ∧ obnašajo pridevniško ( ujemanje spol · število · sklon ); od 5 naprej je sklanjanje neobvezno; sto · tisoč · milijon smejo ostati nesklanjani ⊢ JS ZRC SAZU ∧ Slovenski pravopis.

## PLASTI

1. ⟨1⟩ ena : samostalnik v EDNINI → ena knjiga · en stol · eno mesto.
2. ⟨2⟩ dva/dve : samostalnik v DVOJINI → dva stola · dve knjigi · dve mesti ⊢ priča: slo-na-dlani.si/znanje/6 ( dvojina: dva telefona, dve mesti, dve knjigi ) dostop 21. 11. 2026.
3. ⟨3–4⟩ trije ∧ štirje : VEDNO sklanjajo ⊢ končnice SP: trije ( treh, trem, tri, treh, tremi ) ∧ štirje ( štirih, štirim, štiri, štirih, štirimi ); v imenovalniku/tožilniku samostalnik v MNOŽINI ( trije prijatelji ); v odvisnih sklonih pridevniško ujemanje : k trem prijateljem · s tremi prijatelji ⊢ JS ZRC SAZU ( isjfr.zrc-sazu.si/sl/svetovalnica ) ∧ bubblegum.la tabela dostop 21. 11. 2026.
4. ⟨5–99⟩ pet … : v imenovalniku ∧ tožilniku samostalnik v RODILNIKU MNOŽINE ( pet knjig ∧ ⟨ne⟩ × pet knjige ); v odvisnih sklonih pridevniško ujemanje ( brez petih knjig · k petim knjigam · o petih knjigah · s petimi knjigami ); pri enicah ∧ enostavnih deseticah prevlada sklanjana oblika, pri visokih sestavljenih pogosta nesklanjana ⊢ Toporišič 2008: 330–331 ( po student.si dostop 21. 11. 2026 ).
5. ⟨100+⟩ sto · tisoč · milijon : lahko nesklanjani; milijon kot samostalnik → jedrni samostalnik v rodilniku množine ( milijon evrov ); milijon kot člen → sklanja se tudi jedro ⊢ Sodobna slovenska slovnica ( sss.ung.si/doku.php?id=glavni_stevniki ) dostop 21. 11. 2026.
6. ⟨SUBJEKT 5+⟩ : glagol v 3. osebi ednine srednjega spola → Pet ljudi je prišlo ⊢ JS ZRC SAZU.
7. ⟨DVA ŠTEVNIKA — EN SAMOSTALNIK⟩ : samostalnik stoji samo enkrat, za ZADNJIM števnikom ∧ v njegovem sklonu → med tremi in šestimi leti ⊢ JS ZRC SAZU.
8. ⟨SAMOSTALNIK SLEDI PREDLOGU⟩ : števnik ⟨ne⟩ določa sklona za sabo, predlog ga: avto z osmimi leti jamstva ∧ ⟨ne⟩ × z osem let ⊢ JS ZRC SAZU ( avto z 8 leti jamstva ).
9. ⟨LOČILNI⟩ dvoje · troje · četvoro · petoro : z množinskimi samostalniki ∧ rodilnikom ( Troje srajc je strgal ) ⊢ SSS.
10. ⟨VRSTILNI⟩ prvi · drugi · tretji : pridevniško sklanjanje po samostalniku ( spol · število · sklon ) ⊢ števniki = pridevniška besedna vrsta ( student.si dostop 21. 11. 2026 ).
11. ⟨ZRCALO-NAPAK⟩ : vsaka številka v izhodu se izmeri po tej tabeli ⊙ ⟨MERILEC-SE-MERI⟩ §52 + ⟨REVIZIJA-BESED⟩ + ⟨register-zetonov⟩.
